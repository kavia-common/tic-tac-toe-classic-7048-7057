# Release Notes

Version 1.0.0

- Centered, responsive 3x3 board
- Modes: Player vs Computer (default) and Player vs Player
- Status: win/lose/draw with clear, accessible text
- Controls below board: mode selection and Restart button
- Modern, minimal, light-themed UI with palette:
  - primary: #2467ec
  - secondary: #ffffff
  - accent: #ffba08
- Accessibility: status announcer for screen readers
- Visual polish: subtle win-line highlighting
- Code quality: TS path aliases, flat ESLint config, Prettier, componentized UI
- Docs: README, RUNNING, FAQ, ARCHITECTURE, API

Notes:
- This is an Expo app. No native Android project is generated by default.
- For a real native build, run: expo prebuild --platform android, then ./android/gradlew assembleDebug.
