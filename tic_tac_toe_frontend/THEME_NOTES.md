# Theme Notes

Use the centralized design tokens from src/theme.ts:
- COLORS: primary, secondary, accent, text, subtext, border, tile, shadow, win, lose, draw
- SPACING: xs, sm, md, lg, xl

Guidelines:
- Prefer primary for CTAs and the 'X' mark.
- Use accent for the 'O' mark.
- Keep backgrounds light (secondary, tile) with subtle borders.
- Maintain generous spacing and rounded corners for a modern, minimal feel.
