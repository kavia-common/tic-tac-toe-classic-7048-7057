# Changelog

## 1.0.0
- Initial release of Tic Tac Toe (Expo)
- Features:
  - Centered, responsive 3x3 board
  - Player vs Computer (default) and Player vs Player modes
  - Clear game status (win/lose/draw)
  - Restart button
  - Modern, minimal, light-themed UI with palette:
    - primary: #2467ec
    - secondary: #ffffff
    - accent: #ffba08
- Accessibility:
  - StatusAnnouncer for screen readers
- Code quality:
  - Organized components (Header, GameBoard)
  - Shared theme tokens and types
  - ESLint and Prettier config
  - TS path aliases
