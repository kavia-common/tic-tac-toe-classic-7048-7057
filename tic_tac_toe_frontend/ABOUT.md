# About

Tic Tac Toe Classic is a modern, minimal Expo (React Native) app.

Features:
- Centered, responsive 3x3 board
- Player vs Computer (default) and Player vs Player modes
- Status display (turns, win/draw)
- Restart button
- Light theme with palette:
  - primary: #2467ec
  - secondary: #ffffff
  - accent: #ffba08

Tech:
- Expo + React Native
- TypeScript
- ESLint (flat config) + Prettier
- Accessible status announcer
- Organized components and shared theme

Run:
- cd tic-tac-toe-classic-7048-7057/tic_tac_toe_frontend
- npm install
- npm run web (or npm start)
